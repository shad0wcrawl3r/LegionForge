LEGIX

A Bazzite-based OS for the original Lenovo Legion Go. Steam's Gaming Mode in your hands; a fast tiling desktop at your desk.

Install Source on GitHub

What you get

Gaming Mode, unchanged

Steam's Gaming Mode works exactly as on Bazzite, with its controller, power and performance tuning for the Legion Go.

A tiling desktop

Switch to Desktop opens niri, a scrolling tiling compositor, with the Noctalia shell. Win+Space opens the app launcher.

Made for no keyboard

Noctalia's lock screen has an on-screen keyboard, so you can lock and unlock by touch. There's one on the desktop bar too.

Lean

No GNOME desktop, no Homebrew, no Waydroid, and only a handful of preinstalled apps. Zen is the browser.

Signed and verified

Every image is signed, and the device checks the signature before installing an update.

Always current

Rebuilt every day on top of Bazzite, so Bazzite and Fedora fixes arrive through Legix. Updates install from Steam's Settings.

Install

  1. Install Bazzite for handhelds, the Deck, GNOME edition, from bazzite.gg.

    Legix needs that edition as its starting point. Other editions use a different security policy, and the switch fails.

  2. Switch to Legix from a terminal, then restart:
    sudo bootc switch ghcr.io/shad0wcrawl3r/legix:latest
systemctl reboot
  3. Turn on signature checking, once, then restart again:
    sudo bootc switch --enforce-container-sigpolicy ghcr.io/shad0wcrawl3r/legix:latest
systemctl reboot
  4. Set Steam's PIN in Gaming Mode under Settings → Security, so Gaming Mode is locked too.

Your files and Bazzite itself stay one step away: pick the previous entry in the boot menu, or run sudo bootc rollback. The README has the full guide.
